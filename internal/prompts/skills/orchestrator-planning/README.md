# orchestrator-planning

Скилл декомпозиции для оркестратора rocket: план фичи как набор поставок для
воркеров (кто, что, в каком порядке, как принимается), а не implementation
plan. Детальные планы с файлами и тестами пишут воркеры по своему
`superpowers:writing-plans`.

Появился по итогам разбора #5894 (2026-11-01): codex-оркестраторы получали
`superpowers:writing-plans`, который требует файлов, сигнатур и тестов, и
исполняли его буквально — план на 79 чекбоксов с кодовыми деталями, ревью
кода внутри планирования. Claude читал тот же скилл как декомпозицию.

Раскладывается в worktree каждого оркестратора рядом с
`orchestrator-brainstorming`, для всех агентов, которые умеют скиллы проекта
(`prompts.WriteOrchestratorPlanningSkill`).
