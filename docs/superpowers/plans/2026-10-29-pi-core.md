# Pi Adapter Core, Journal, and Catalog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an internal Pi agent adapter with correct launch/workspace behavior, exact session-journal discovery, resilient JSONL helpers, and a live/fallback model catalog.

**Architecture:** Implement `agent.Agent` in a new `internal/agent/pi` package, registering it only from that package. Reuse Rocket's workspace helpers and the established reverse-block JSONL reader pattern; locate Pi journals by physical-worktree directory and exact session ID. Query `pi --list-models` through a replaceable runner and return a builtin DeepSeek snapshot on failure without validating or restricting manual model names.

**Tech Stack:** Go standard library, existing `internal/agent` and `internal/prompts` helpers, Go `testing`.

**Spec:** `/Users/ivanroslov/.rocket/worktrees/rocket/pi-and-deepseek2-orch/.superpowers/sdd/2026-10-29-pi-deepseek-agents/task-2-brief.md` and `/Users/ivanroslov/.rocket/worktrees/rocket/pi-and-deepseek2-orch/docs/superpowers/specs/2026-10-29-pi-deepseek-agents-design.md`

## Global Constraints

- Keep `internal/agent/pi` internal until Task 6: no daemon/CLI imports or production exposure.
- No new dependencies, subagents, unrelated refactors, global Pi settings/auth/package changes, activity, delivery, chat, or Usage implementation.
- `activity.go` and `chat.go` contain only `agent.ErrNoSignal` stubs.
- Use `agent.UpsertAgentsMD(..., false)`, `prompts.WriteOrchestratorSkill`, and `agent.ExcludeFromGit`.
- Forward only the selected provider's nonempty official API-key variable; never set `PI_CACHE_RETENTION`.
- Journal records may exceed 64 KiB; malformed and partial lines must not invalidate good records.
- Catalog CLI timeout is 10 seconds; fallback never restricts manual `provider/model` profiles.
- Follow red/green TDD and commit the two implementation units separately.

## Review Focus

- A symlink named like a matching journal must not redirect reads to another session; Task 2 tests regular-file-only discovery.
- A newest journal for another worktree or session must not win; Task 2 tests both physical-path and exact-ID filters.
- A valid record larger than one reverse block and an unterminated malformed suffix must be handled independently; Task 2 tests both in one file.
- A trailing standalone usage/custom record must not change the active conversation leaf; Task 2 tests branch reconstruction with non-conversation records.
- Empty credentials, unknown providers, and manual models must remain safe and usable; Tasks 1 and 2 test env filtering and unvalidated launch model passthrough respectively.
