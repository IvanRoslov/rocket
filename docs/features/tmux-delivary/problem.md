# Проблема

Пользователь Rocket работает с несколькими терминальными агентами: Claude Code, Codex, Kimi и Pi, в том числе с DeepSeek. В Claude Code внутренние сообщения Rocket доставляются через отдельный сокет и не мешают ручному вводу. Для остальных агентов Rocket отправляет сообщения в строку ввода через tmux. Если человек в этот момент набирает текст, внутреннее сообщение может заменить или испортить его ввод. Существующие проверки наличия введённых символов не дают надёжной защиты.

Нужно исследовать возможности tmux, его расширений и интерфейсов самих агентов, чтобы найти способ доставлять внутренние сообщения без повреждения текста человека. Успех — обоснованное решение с понятными ограничениями для каждого агента и планом проверки одновременного ручного ввода и автоматической доставки. Предпочтение — отдельному каналу, похожему по свойствам на доставку Claude, если он доступен.
