# Проблема

Живой worker DeepSeek через Claude Code не получает review feedback от Rocket. Работа идёт, но проверка результата блокируется. Выбранную Иваном модель менять нельзя.

Rocket должен штатно доставлять сообщение точно нужному экземпляру, подтверждать получение по его журналу и не отправлять повторно при неизвестном результате. Ложное событие завершения не должно объявлять живой процесс умершим; настоящий выход и блокировка должны сохраняться. Смена беседы в том же процессе не должна требовать ручной настройки.

По решению Ивана5911/Q9 выпускаем проверенное исправление, затем Иван обновляет и перезапускает Rocket. Приёмку проводим на новой DeepSeek-сессии. Подключение старых процессов без доказанного запуска не разрабатываем. Старое сообщение с неизвестным результатом не переносим и автоматически не повторяем. Перезапуск одного daemon не создаёт новый Claude-процесс.

Успех — доказанная доставка через обычный rocket send без смены модели, потери ввода, ручного injection, подмены activity/реестра или вмешательства в Variables. До готовности кода не трогаем живые сессии, демон, глобальные настройки и секреты. Слияние требует независимого review и обязательных проверок; установка и живая проверка выполняются по отдельному конкретному порядку.
