# Дашборд (заглушка)

Детальный дизайн будет написан отдельным документом перед фазой 6. Здесь фиксируются уже принятые решения:

- **Стек:** TypeScript + React. Отдельный пакет `web/` в репозитории; продакшен-сборка — статические файлы, которые раздаёт сам `rocketd` на `127.0.0.1:<port>`.
- **Источник данных:** только публичный API демона ([03-daemon-api.md](03-daemon-api.md)): REST + SSE `/v1/events/stream`. Никаких приватных каналов — всё, что умеет дашборд, умеет и curl.
- **Концептуально другой, чем в AO:** не список сессий по проектам; главная единица UI — фича/оркестратор с его воркерами. Конкретика — в будущем дизайн-доке.
- Терминальный доступ к сессиям (xterm.js через WebSocket) — рассматривается в дизайне фазы 6, в API v1 не входит.
