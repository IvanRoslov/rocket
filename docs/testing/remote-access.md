# Удалённый доступ к rocket (Tailscale + сопряжение устройств)

Демон по TCP всегда требует токен устройства (даже с 127.0.0.1); unix-сокет работает без авторизации. Схема: демон слушает только localhost, `tailscale serve` публикует его в tailnet по HTTPS, устройства (телефон, браузер) сопрягаются одноразовым кодом.

## Настройка

1. Установи Tailscale на Mac и на телефон, войди в одну tailnet.
2. На Mac: `tailscale serve --bg 4477` — получишь `https://<mac>.<tailnet>.ts.net`.
3. В `~/.rocket/config.yaml`:

   ```yaml
   host: 127.0.0.1
   public_url: https://<mac>.<tailnet>.ts.net
   ```

   затем `make restart`. Проверь: `rocket doctor` — строки `listen`, `public_url`, `tailscale` без предупреждений.
4. Телефон: `rocket pair` покажет QR и код `XXXX-XXXX` (живёт 10 минут, одноразовый). В приложении на экране серверов нажми «Сканировать QR» или введи адрес и код вручную. Браузер: `rocket pair --web` напечатает одноразовую ссылку с входом (открой её в браузере); QR для телефона также есть в вебе: Settings → Devices.
5. Управление устройствами: `rocket devices ls`, `rocket devices revoke <id>`.

## Проверка

- [ ] Телефон на 4G (Wi-Fi выключен, Tailscale включён): канбан открывается, чат работает, SSE-обновления приходят вживую.
- [ ] Веб-терминал открывается через `https://<mac>.<tailnet>.ts.net`.
- [ ] Из LAN без Tailscale: `curl http://<lan-ip>:4477/v1/health` — connection refused.
- [ ] `curl http://127.0.0.1:4477/v1/health` — `401 unauthorized` (TCP всегда требует токен).
- [ ] Код, введённый вручную в нижнем регистре, с дефисом или с `O` вместо `0`, принимается.
- [ ] `rocket devices revoke <id>` для телефона — в приложении в течение нескольких секунд появляется баннер «Доступ к серверу отозван», кнопка «Подключить» открывает сканер.
- [ ] Повторное использование того же кода и 5+ неверных попыток подряд — «Код неверный…» / «Слишком много попыток».

> Примечание: лимитер сопряжения глобальный — любой, кто достаёт до TCP-порта (участник tailnet или LAN при `host: 0.0.0.0`), может исчерпать его неудачными попытками (5 в минуту → `429 rate_limited`). Подожди минуту и повтори.
