# Разбор дизайн-мокапов дашборда

Источник: Claude Design проект `1d40602d-fa51-44cf-90bc-d6896f045894`. Файлы `*.dc.html` в этой папке — нормативный дизайн; открываются локально (рантайм `support.js`). Разметка в `<x-dc>`, логика мокапа в `<script data-dc-script>`.

## Ключевые дизайн-токены

- **Тема только светлая**; тёмные поверхности точечно — терминал и лог (`#161618`, шапка `#1f1f22`, текст `#d4d4d8`/`#e4e4e7`, лог-зелёный `#a7d3a7`).
- Фон страницы `#f6f6f4`; поверхности `#fff`, вторичные `#f0f0ee`/`#f4f4f2`/`#fafafa`, рейл `#fbfbfa`; границы `#e7e7e4` (hover `#d4d4d1`), тонкие разделители `#f0f0ee`/`#f7f7f5`.
- Текст: `#1a1a1c` основной, `#52525b`/`#3f3f46` вторичный, `#71717a` приглушённый, `#a1a1aa` слабый.
- Акцент indigo: `#4f46e5` (hover `#4338ca`), выбор `#eef2ff`+`#c7d2fe`, текст `#3730a3`. Успех: `#16a34a`/`#166534`/`#dcfce7`/`#f0fdf4`/`#bbf7d0`. Предупреждение/awaiting: `#d97706`/`#b45309`/`#92400e`, фоны `#fef3c7`/`#fffbeb`, бордеры `#fcd34d`/`#fde68a`. Ошибка: `#dc2626`/`#b91c1c`/`#991b1b`, фоны `#fee2e2`/`#fef2f2`, бордер `#fecaca`. Review-фиолетовый: `#7c3aed`/`#6b21a8`/`#f3e8ff`. Нейтральный бейдж `#52525b` на `#f1f5f9`.
- Шрифты: UI `system-ui,-apple-system,"Segoe UI",sans-serif`; моно `ui-monospace,monospace` (id, имена сессий/репо, счётчики, терминал). Заголовки вес 650, letter-spacing −.01/−.02em.
- Радиусы: панели 10–14px, кнопки 7–10px, бейджи 5–7px, пилюли 20px. Кнопки: primary чёрная `#1a1a1c`, secondary белая с бордером `#d4d4d1`, danger — белая с красным текстом.
- **Общая шапка** (52px, sticky, белая): лого «R» (чёрный квадрат 22px) + `rocket` моно; переключатель проекта (зелёная точка, имя, моно-id, ▾; дропдаун 280px с поиском); справа табы Projects/Kanban/System/Settings (активный на `#f0f0ee`).

## Экраны

**Projects** (`Projects.dc.html`) — main 1180px, сетка карточек `auto-fill minmax(340px,1fr)`. Карточка: точка статуса + имя + моно-бейдж id; строка `⌂ main + linked`; стат-бейджи («2 in progress» indigo, «1 review» фиолетовый, «● 5 live» зелёный, «idle» серый); футер: сигналы «? awaiting you» (жёлтый бейдж, приоритетный) и «⚠ 1 problem» + «updated 12m ago». Пунктирная карточка «＋ Create project». Кнопка «＋ New project» → визард.

**Kanban** (`Kanban.dc.html`) — 100vh без прокрутки страницы; саб-хедер: имя проекта, поиск задач, чекбокс «Show cancelled», шестерёнка. Колонки 296px на `#f0f0ee`: Backlog (серая точка, кнопка ＋), In Progress (indigo), Review (фиолетовая), Done (зелёная), с пилюлями-счётчиками. Карточка задачи: `#id` + заголовок (→ Task), строка `api → web, infra`, «orch: active · 3 workers» с точкой активности, PR-бейджи («2 PR open»/«1 merged»/«CI ✔»/«CI running»), сигналы за разделителем, у Backlog — чёрная кнопка «Start ▸» во всю ширину. Drag-n-drop: перетаскиваемая карточка opacity .4, колонки подсвечиваются бордером `#c7d2fe`.

**Task** (`Task.dc.html`) — самый насыщенный: слева контент 820px, справа рейл сессий 312px, поверх — терминал-оверлей. Заголовок `#12 Billing v2` + бейдж статуса + мета (`feature/billing-v2`, created/updated). Жёлтый баннер открытого вопроса над табами («? awaiting you · Q3 · текст · Open thread →»). Табы Questions/Overview/Docs/Journal/Messages со счётчиками (Questions жёлтый при awaiting) и чёрным подчёркиванием активного. Questions: карточка-тред с жёлтой шапкой (Q-тег, чья очередь, автор), крупный вопрос, сворачиваемый Context (моно), тред с квадратными аватарами (O жёлтый/Y indigo) и статусом доставки реплик, внизу textarea + «Clarify — keep open» / «Answer & close» (чёрная) / «Dismiss as not relevant»; ниже свёрнутые Resolved. Overview: описание, список подзадач (точка, #id, title, `session · repo`, бейдж статуса, PR-колонка), placeholder «Final report». Docs: карточки с бейджем kind (spec/plan/doc), версией, выдержкой. Journal: фильтры-пилюли + вертикальный таймлайн с цветными точками и бейджами kind. Messages: чат-пузыри (свои справа indigo `#eef2ff` со статусом «✓ delivered», оркестратор слева белые), sticky-ввод + «Send». Рейл: карточка Orchestrator («▣ term» чёрная, «attach ⧉» с подтверждением «copied: rocket attach …», «kill» красная) и карточки Workers (состояние ready/blocked/working + PR). Терминал: оверлей `rgba(15,15,17,.55)`+blur, тёмная панель, шапка с именем сессии/«tmux · live attach»/«80×24»/attach/Close, тело моно 13.5px с мигающим зелёным курсором; клик по фону закрывает.

**NewProject** (`NewProject.dc.html`) — узкий визард 640px со степпером из 4 шагов (текущий чёрный круг, пройденные зелёные с ✓, линии зеленеют). Шаг 1: Name + Project id (моно) с инлайн «● available». Шаг 2: сегмент-табы GitHub/Registered/Local path; GitHub — поиск + скролл-список (моно-имя, бейдж private, default branch, выбранный indigo с ✓); Registered — с «used in: …»; Local path — моно-поле + зелёная панель «✓ valid git repo / origin / default branch». Шаг 3: те же списки с indigo-чекбоксами, счётчик selected, строка «Selected: web, infra» / «none (single-repo project)». Шаг 4: таблица-сводка + «Create project ✓» → канбан. Навигация «← Back» / «Continue →» / «Review →».

**Settings** (`Settings.dc.html`) — grid `180px 1fr`, слева sticky-меню (GitHub/Repositories/Project/Daemon). GitHub: зелёная плашка «Authorized as @acme-bot», маскированный токен `ghp_••••3f2a` + Save, подпись про repo scope. Repositories: реестр — моно-id + бейдж «rocket»/«user», origin, «used in: …», Remove активен красным только у незанятых. Project: Name, чипы репо (main `⌂ api` indigo без удаления, linked с ✕, пунктирная «＋ linked»), красная danger-зона Delete (disabled с пояснением). Daemon: read-only ключ-значение (port, socket, интервалы, пути, db).

**System** (`System.dc.html`) — 4 стат-карточки (Live sessions, Agents running, Orphans жёлтым, Queue depth); grid `1.6fr 1fr`: слева таблица «tmux sessions & agents» (session/kind/agent/state, бейджи состояний, включая orphan); справа Message queue (плитки queued/failed + красная моно-плашка `msg#812 … recipient busy · retry`), Worktrees on disk (пути + размеры, сумма), Daemon (status/version/socket/uptime). Внизу тёмный лог-хвост `rocketd.log` (`tail -f`, зелёный моно). Кнопка «⌦ Cleanup orphans» в заголовке.

**support.js** — сгенерированный рантайм dc-мокапов (~66KB): парсит `<x-dc>`-шаблон и `data-dc-script`, рендерит через `window.React`; для реализации дашборда не нужен, только чтобы открывать мокапы локально.
